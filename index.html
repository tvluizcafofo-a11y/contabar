🆕 Comandos Principais

  • "Ver conta parcial"
    Mostra o subtotal atual e quantidade de itens
  • "Abrir conta"
    Cria uma nova conta
  • "Incluir produtos [nome] [valor]"
    Ex: "incluir produtos cerveja 10 reais"
  • "Incluir produtos [nome]"
    Ex: "incluir produtos cerveja" - abre cadastro com nome
  • "Incluir cliente [nome]"
    Ex: "incluir cliente João Silva"
  • "Incluir estabelecimento [nome]"
    Ex: "incluir estabelecimento Bar do Zé"
  • "Selecionar estabelecimento [nome]"
    Ex: "selecionar Bar do Zé"
  • "Ver cardápio"
    Exibe o cardápio do estabelecimento ativo
  • "Ver histórico"
    Mostra o histórico de contas fechadas

📂 Comandos de Navegação

  • "Abrir cardápio"
    Abre a tela de cardápio
  • "Abrir estabelecimentos"
    Abre a tela de estabelecimentos
  • "Abrir pedido"
    Abre a tela de pedidos
  • "Mostrar conta"
    Abre a tela da conta e fala o subtotal

🛒 Comandos de Pedido

  • "Fazer pedido de [qtd] [produto]"
    Ex: "fazer pedido de 2 cervejas"
  • "Adicionar [qtd] [produto]"
    Ex: "adicionar 3 águas"
  • "Pedir [qtd] [produto]"
    Ex: "pedir uma porção de batata"
  • "Solicitar [qtd] [produto]"
    Ex: "solicitar 2 cervejas"
  • "Mais uma [produto]"
    Ex: "mais uma cerveja" (adiciona 1)
  • "Mais um [produto]"
    Ex: "mais um refrigerante" (adiciona 1)

💰 Comandos de Conta

  • "Fechar conta"
    Finaliza a conta, calcula gorjeta e mostra o total
  • "Ver conta parcial"
    Mostra o subtotal atual

⚙️ Comandos de Controle

  • "Desativar comando por voz"
    Desativa o assistente de voz
  • "Desligar comando por voz"
    Sinônimo de "desativar"
  • "Desligar app"
    Fecha o aplicativo (tenta fechar a página)

💾 Comandos de Dados

  • "Exportar dados"
    Exporta todos os dados do app para um arquivo JSON
  • "Importar dados"
    Importa dados de um arquivo JSON (abre a tela de dados)
  • "Limpar histórico"
    Remove todo o histórico de contas
  • "Limpar dados"
    Remove TODOS os dados (produtos, pedido, histórico, etc.)

💡 Dica: Você pode falar números como "um", "dois", "três" ou usar números escritos como "2", "3", "10".
