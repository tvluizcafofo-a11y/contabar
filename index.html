🎯 Lista Completa de Comandos de Voz

💡 Dica: Todos os comandos abaixo são personalizáveis! Vá em ⚙ Configurações → 🎤 Sinônimos de Voz para adicionar ou remover palavras.

🧠 Nome parcial de produto: ao fazer um pedido, você pode falar só parte do nome. Se o cardápio tem "Cerveja Império", basta dizer "desce uma império".

🖱️ Botões por voz: quando um modal estiver aberto (pagamento, compartilhar, etc.), basta falar o nome do botão para acioná-lo. Ex: "pix", "dinheiro", "cartão", "whatsapp", "fechar".

Todos os comandos disponíveis para controle por voz do sistema.

🏢 Estabelecimentos

  • "Selecionar [nome]"
    Ex: "selecionar Bar do Zé"
  • "Incluir estabelecimento [nome]"
    Ex: "incluir estabelecimento Bar do Zé"
  • "Ver cardápio"
    Exibe o mini cardápio do estabelecimento ativo

🍺 Produtos

  • "Incluir produtos [nome] [valor]"
    Ex: "incluir produtos cerveja 10 reais"
  • "Incluir produtos [nome]"
    Abre o cadastro com o nome preenchido

🛒 Pedidos & Conta

  • "Pedir [qtd] [produto]"
    Sinônimos: pedir, pega, me dá, desce, traz, quero, mais um...
  • "Pedir [qtd] [parte do produto]"
    Ex: "desce uma império" → acha "Cerveja Império"
  • "Mais uma [produto]"
    Adiciona 1 unidade

💰 Conta

  • "Abrir conta"
    Nova conta no estabelecimento ativo
  • "Abrir conta [nome]"
    Seleciona o estabelecimento e abre a conta
  • "Mostrar conta"
    Abre a tela da conta
  • "Fechar conta"
    Finaliza a conta

💳 Pagamento (com modal aberto)

  • "Pix"
    Aciona o botão PIX
  • "Dinheiro"
    Aciona o botão Dinheiro
  • "Cartão"
    Aciona o botão Cartão

📜 Histórico

  • "Ver histórico"
    Mostra o histórico de contas
  • "Limpar histórico"
    Remove todo o histórico

💾 Dados

  • "Exportar dados"
    Exporta todos os dados para JSON
  • "Importar dados"
    Abre a tela de importação
  • "Limpar dados"
    Remove TODOS os dados

⚙ Controle

  • "Desativar comando por voz"
    Desliga o assistente
  • "Desligar app"
    Fecha o aplicativo

✅ Confirmação por Voz

  • "Sim" / "Confirmo" / "Claro" / "Pode"
    Confirma uma ação solicitada pelo app
  • "Não" / "Cancela" / "Negativo"
    Recusa uma ação solicitada pelo app

💡 Dica: Números falados: "um", "dois", "três" ou "2", "3", "10".
